# Reed-Solomon Lab 🔬

Полнофункциональный интерактивный стенд для изучения кодов Рида-Соломона — алгоритмов помехоустойчивого кодирования.

## Возможности

### 📊 Мультирежимный демонстратор
- **5 различных конфигураций кодов** (RS(17,15) до RS(17,7))
- **Ошибки vs Стирания** — два режима коррупции данных
- **Интерактивный выбор символов** — нажимайте на символы для их повреждения

### 🎯 Интерактивные сценарии
Предустановленные демонстрации:
1. **✓ Успешное восстановление** — 2 ошибки в пределах возможности кода
2. **⚠ На пределе способности** — 3 ошибки = максимум для RS(6)
3. **✗ Превышена способность** — 4 ошибки = невозможно восстановить
4. **Стирания (erasures)** — когда позиции повреждений известны
5. **Слабый код** — демонстрация RS(17,15) с минимальной защитой
6. **Сильный код** — демонстрация RS(17,7) с максимальной защитой

### 📚 Теория
- **Полное объяснение** как работают коды Рида-Соломона
- **Параметры кода** и их влияние на способность коррекции
- **Практические применения** в реальных системах

### 📈 Статистика и информация
- Отображение проверочных символов с объяснением

## Как это работает

### Кодирование
```
ИСХОДНЫЕ ДАННЫЕ (5-11 байтов)
         ↓
    [RS КОДЕР]
         ↓
КОДОВОЕ СЛОВО = ДАННЫЕ + ПРОВЕРОЧНЫЕ СИМВОЛЫ
(5+6=11 байтов для RS-6)
```

### Передача через шумный канал
```
ИСХОДНОЕ КОДОВОЕ СЛОВО
         ↓
    [ШУМНЫЙ КАНАЛ]
    (ошибки / стирания)
         ↓
ПОВРЕЖДЁННОЕ КОДОВОЕ СЛОВО
```

### Декодирование
```
ПОВРЕЖДЁННОЕ КОДОВОЕ СЛОВО
         ↓
    [RS ДЕКОДЕР]
    (полиномиальная арифметика)
         ↓
ВОССТАНОВЛЕННЫЕ ИСХОДНЫЕ ДАННЫЕ
```

## Параметры кодов

| Код | Проверочные символы | Исправляет ошибок | Восстанавливает стираний |
|-----|-------------------|-----------------|------------------------|
| RS(17,15) | 2 | 1 | 2 |
| RS(17,13) | 4 | 2 | 4 |
| RS(17,11) | 6 | 3 | 6 |
| RS(17,9) | 8 | 4 | 8 |
| RS(17,7) | 10 | 5 | 10 |

### Формула Сингтона

Для кода RS с `nsym` проверочными символами:
- **Способность к коррекции ошибок** = floor(nsym / 2)
- **Способность к восстановлению стираний** = nsym
- **Минимальное расстояние Хэмминга** = nsym + 1

## API Endpoints

### `POST /api/encode`
Кодирует сообщение в кодовое слово RS.

```bash
curl -X POST http://localhost:5001/api/encode \
  -H "Content-Type: application/json" \
  -d '{"message": "HELLO", "nsym": 6}'
```

Ответ:
```json
{
  "data": [72, 69, 76, 76, 79],
  "parity": [45, 209, 3, 237, 187, 235],
  "codeword": [72, 69, 76, 76, 79, 45, 209, 3, 237, 187, 235],
  "config": {
    "name": "RS(17,11)",
    "total_codeword_length": 11,
    "correction_capability": 3,
    "erasure_capability": 6
  }
}
```

### `POST /api/corrupt`
Добавляет ошибки или стирания в кодовое слово.

```bash
curl -X POST http://localhost:5001/api/corrupt \
  -H "Content-Type: application/json" \
  -d '{
    "message": "HELLO",
    "positions": [2, 5],
    "mode": "error",
    "nsym": 6
  }'
```

### `POST /api/decode`
Декодирует повреждённое кодовое слово.

```bash
curl -X POST http://localhost:5001/api/decode \
  -H "Content-Type: application/json" \
  -d '{
    "corrupted": [72, 69, 179, 76, 79, 210, 209, 3, 237, 187, 235],
    "nsym": 6
  }'
```

### `GET /api/scenarios`
Получить список интерактивных сценариев.

## Граничные случаи

### Слишком много ошибок
Если выбрать больше ошибок, чем может исправить код:
- Отображается предупреждение
- Попытка декодирования завершится неудачей
- Показывается информация о превышении способности

### Стирания vs Ошибки
- **Стирание**: известна позиция повреждения, неизвестно значение
- **Ошибка**: неизвестна позиция, неизвестно значение
- Стирания требуют меньше проверочных символов!

## Математика под капотом

Коды Рида-Соломона работают в конечных полях (полях Галуа GF(256)):
1. Исходные данные рассматриваются как коэффициенты полинома P(x)
2. Проверочные символы — это значения P(x) в дополнительных точках
3. При декодировании восстанавливается исходный полином
4. Если слишком много ошибок, восстановление невозможно
